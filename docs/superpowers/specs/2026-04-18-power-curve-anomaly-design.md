# 功率曲线异常检测设计文档

**日期**: 2026-04-18
**子项目**: C（功率曲线异常检测）
**目标**: 检测风电场功率曲线中的异常数据点，识别限电、故障等异常运行状态，辅助数据清洗和运行监控

---

## 1. 概述

通过统计方法对电场级风速-功率数据进行异常检测，构建功率曲线置信带，将偏离正常范围的点标记为异常并分类（离群点、限电、欠发），为数据清洗、运行监控和风机性能评估提供依据。

**核心目标**：
1. **数据清洗** — 识别异常数据点，标记后排除出模型训练数据
2. **运行状态监控** — 检测限电、故障等异常状态，及时告警调度员
3. **风机性能评估** — 监控实际功率曲线与理论曲线的偏差

**非目标**（不在本子项目范围）：
- 风机级别检测（仅电场级）
- 实时流式检测（仅按需前端计算）
- 自动修复异常数据

---

## 2. 技术路线

**选择**: 统计方法 — 风速分箱 + 置信带

- 按风速分箱（0.5 m/s），计算每档功率的均值和标准差
- 构建正常功率曲线置信带（均值 ± 2σ）
- 偏离置信带的点标记为异常，按偏离模式分类

**未选择方案及原因**：
- 机器学习（Isolation Forest / One-Class SVM）：精度高但复杂度大，且需要训练数据和调参
- 混合方法：增加系统复杂度，统计方法已足够覆盖三种异常类型

---

## 3. 数据层

### 3.1 数据来源

复用现有数据表，无需新增表：

- `theoretical_power_data` 表：`wind_speed_hub`（轮毂数风速）、`theoretical_power`（理论功率）
- `actual_power` 表：`wp_avg`（实际平均功率）

前端通过已有运营数据 API 获取指定时间段的风速和功率数据，本地计算异常。

### 3.2 数据约束

- 需要同一时间戳有风速和功率的配对数据
- 典型数据量：一个月约 2880 个 15 分钟点，前端完全可以处理
- 数据缺失时段不计入检测

---

## 4. 检测算法

### 4.1 分箱统计

```
风速范围: 0 - 25 m/s
分箱宽度: 0.5 m/s
每个分箱计算: 功率均值 μ, 功率标准差 σ
最小样本数: 分箱内 < 5 个点时跳过
```

### 4.2 置信带

- 正常带：μ ± 2σ（覆盖约 95% 正常数据）

### 4.3 异常分类规则

| 类型 | 判定条件 | 典型原因 |
|------|----------|----------|
| **离群点** | 单点偏离置信带 > 3σ，且周围 3 个时间步内无连续异常 | 传感器故障、数据通信错误 |
| **限电** | 风速 > 额定风速，功率持续低于上界且方差极小（σ < 0.05 × capacity），连续 ≥ 5 个点 | 调度指令限电 |
| **欠发** | 功率持续低于下界（非限电模式），连续 ≥ 5 个点 | 叶片污染、偏航故障、机械问题 |

### 4.4 边界处理

- 切入风速（通常 3 m/s）以下不计为异常
- 切出风速（通常 25 m/s）以上不计为异常
- 功率 = 0 且风速 < 切入风速视为正常停机

## 5. 前端可视化与交互

### 5.1 页面结构

在侧边栏新增"功率曲线分析"入口，独立页面展示。

### 5.2 图表元素（ECharts 散点图）

- 灰色理论功率曲线（参考线）
- 绿色置信带（上下界之间的半透明区域）
- 正常数据点（绿色小圆点）
- 离群点（紫色标记）
- 限电点（红色标记）
- 欠发点（橙色标记）
- 图例可切换各类型显示/隐藏

### 5.3 交互控件

- 日期范围选择器（默认最近 7 天）
- 电场选择（复用 FarmSelector）
- 异常类型筛选 checkbox
- 统计摘要卡片：总数据点数、异常点数、异常率、各类异常数量

### 5.4 告警集成

异常率超过 15% 时，自动调用告警 API 创建 AlarmRecord 写入告警中心。

---

## 6. 数据清洗集成

### 6.1 质量标记联动

检测到的异常点可一键标记到已有的 `DataQualityManagement` 质量标记系统：
- 标记类型："功率曲线异常"
- 附带异常分类（离群/限电/欠发）
- 标记后自动设置 `exclude_from_score` 标志

### 6.2 排除训练数据

标记为异常的数据点在后续模型训练时自动排除，提升预测精度。

## 8. 约束与边界

- 检测粒度：电场级（聚合功率 vs 平均风速）
- 计算方式：前端实时计算，无需后端定时任务
- 分箱最小样本数：5 个点，不足时跳过该分箱
- 连续异常判定阈值：≥ 5 个连续点
- 切入/切出风速边界保护
- 异常率告警阈值：15%
