# 首页大屏 UI 重设计方案

**日期:** 2026-05-06
**方案:** A — 经典仪表盘
**目标受众:** 工程师工作台（高信息密度、可交互）
**视觉风格:** 保持现有科幻深色主题，优化布局和对齐

## 问题诊断

当前首页大屏存在 4 个核心问题：

1. **卡片未对齐** — 左右两栏高度不一致，flex 比例分配导致视觉不齐
2. **空间分配不合理** — KPI 区域仅 1 张卡片却占一整行；任务矩阵纵向被压缩
3. **数据展示不清晰** — 缺少核心运营指标；趋势图缺少时间范围选择
4. **缺乏视觉层次** — 所有面板视觉权重相同，没有主次之分

## 总体布局

```
┌─────────────────────────────────────────────────┐
│  header: 标题 + 更新时间 + 刷新按钮 (flex-shrink:0)│
├─────────────────────────────────────────────────┤
│  KPI: [准确率] [总功率] [发电量] [开机率]  (固定高度) │
├──────────────────────┬──────────────────────────┤
│                      │  气象概览 (~40%)          │
│  功率趋势图           ├──────────────────────────┤
│  (flex:1, 2/3宽)     │  任务监控矩阵 (~60%)      │
│                      │                          │
└──────────────────────┴──────────────────────────┘
```

CSS Grid 结构：
- 外层 `grid-template-rows: auto auto 1fr`（header / KPI / 主体）
- 主体 `grid-template-columns: 2fr 1fr`，gap: 12px
- 所有 panel-card 统一 `padding: 14px`，`border-radius: 10px`

## 设计细节

### 1. KPI 卡片行

顶部一行横排 4 个关键指标卡片，等宽等高。

| 卡片 | 主题色 | 主数值 | 补充信息 |
|------|--------|--------|----------|
| 综合预测准确率 | 青 `#12d7ff` | 87.3% | 短期 89.1% / 超短期 85.5%（竖线分隔） |
| 当前总功率 | 绿 `#2dd36f` | 245.6 MW | 装机容量 350MW，负荷率 70.2% |
| 今日发电量 | 黄 `#fbbf24` | 1,842 MWh | 较昨日 ↑ 12.3% |
| 风机开机率 | 紫 `#a78bfa` | 93.5% | 在线 56/60，故障 2 |

样式规范：
- `grid-template-columns: repeat(4, 1fr)`
- 每张卡片：主题色渐变背景（135deg），右上角径向渐变装饰
- 数字用 Consolas 等宽字体 28px bold
- 卡片底部 1px 分隔线 + 补充信息行（10-12px）
- 统一 `border-radius: 10px`，`padding: 16px`

数据来源：
- 准确率：`getDashboardOverview` 返回的 cards 数据（已有）
- 总功率/发电量/开机率：需在 `getDashboardOverview` 后端接口中新增计算逻辑

### 2. 功率趋势图增强

保留现有 `PowerTrendChart.vue` 组件，增强交互功能：

- **时间范围切换**：标题栏右侧增加按钮组 `1D | 3D | 7D`（默认 1D）
- **图例交互**：图例独立为可点击行，点击可隐藏/显示对应曲线
- **Tooltip 增强**：显示时间、实际功率、短期预测、超短期预测、容量的具体数值
- **DataZoom**：默认展示最近 24h，支持拖拽缩放
- 占据左侧主体（2/3 宽度），flex:1 撑满剩余高度

数据来源：`getDashboardTrend` 接口，前端根据选择的时间范围调整请求数据量。

### 3. 气象概览

保留现有 5 个指标，优化布局：

- 改为 2 列网格（而非 3 列），每个指标卡片更大更易读
- 最后一个指标（湿度）跨两列或居中
- 每个指标卡片结构：图标+标签在上，数值（16px Consolas）+单位在下
- 右上角保留 NWP 更新时间
- 占右侧面板约 40% 高度

### 4. 任务监控矩阵

保留现有 `FleetMap.vue` 组件，优化视觉：

- 表头行增加背景色区分（`rgba(18,215,255,0.06)`）
- 场站名左对齐，状态列居中
- 底部图例改为水平排列
- 占右侧面板约 60% 高度

## 涉及的文件

| 文件 | 改动 |
|------|------|
| `frontend/src/components/HomePage.vue` | 重构布局：从两栏改为 header+KPI+主体三行布局 |
| `frontend/src/components/dashboard/KpiCards.vue` | 重写：支持 4 卡片横排，主题色卡片样式 |
| `frontend/src/components/dashboard/PowerTrendChart.vue` | 增强：时间范围按钮组、图例交互、Tooltip |
| `frontend/src/components/dashboard/FleetMap.vue` | 微调：表头样式、图例布局 |
| `frontend/src/assets/theme.css` | 新增 KPI 卡片相关的 CSS 变量 |
| `frontend/src/services/dashboardService.js` | 扩展 `getDashboardOverview` 返回更多 KPI 数据 |
| `backend/services/dashboard_service.py` 或相关路由 | 新增总功率、发电量、开机率的计算接口 |

## 不做的事

- 不改变整体视觉风格（保持科幻深色）
- 不增加新的数据图表类型（场站排名柱状图、事件列表暂不接入）
- 不做响应式断点的重大调整（保持 1280px / 720px 断点）
- 不引入新的 UI 框架或 CSS 库
