# 自适应特征分布校正配置文件说明

## 概述

本目录包含风电功率预测系统的**自适应特征分布校正配置文件**，采用智能决策机制自动区分正常概念漂移和数据环境迁移，在保护知识产权的同时确保授权场站的最优性能。

### 系统升级亮点
- **智能自适应**: 从固定惩罚模式升级为自适应决策系统
- **概念漂移处理**: 自动识别并适应正常的数据演化
- **动态基准更新**: 在授权环境下自动学习和更新基准指纹
- **保护机制**: 在环境迁移时启动保护性降级

## 配置文件类型

### 短期预测配置
- **文件名**: `feature_scaling_parameters_short.json`
- **用途**: 短期风电功率预测（通常1-6小时）
- **特征工程**: 基于高频数据的时间窗口特征
- **更新频率**: 建议每月更新一次

### 中期预测配置  
- **文件名**: `feature_scaling_parameters_middle.json`
- **用途**: 中期风电功率预测（通常6-72小时）
- **特征工程**: 基于中频数据的扩展时间窗口特征
- **更新频率**: 建议每月更新一次

```json
{
  "metadata": {

    "source_file": "training_data.csv",
    "prediction_type": "short",
```

### 关键参数说明
- **adaptation_threshold**: 自适应决策阈值（默认0.15，即15%偏移）
- **auto_update_enabled**: 是否启用自动基准更新
- **backup_generations**: 保留的备份文件数量
- **decision_history**: 历史决策记录，用于审计和分析

## 技术原理

### 自适应决策系统架构

#### 1. 总体分布偏移评估
系统计算当前数据与基准数据的总体偏移分数：
```
shift_score = Σ(0.7 × mean_deviation + 0.3 × std_deviation) / feature_count
```

#### 2. 智能决策逻辑
基于偏移分数与阈值比较：
- **偏移分数 < 阈值**: 适应模式，保持最优性能 + 更新基准
- **偏移分数 ≥ 阈值**: 保护模式，启动特征重要性惩罚

#### 3. 特征稳定性评估
采用归一化偏差计算方法：
- **均值偏差**: `|current_mean - baseline_mean| / |baseline_mean|`
- **标准差偏差**: `|current_std - baseline_std| / |baseline_std|`

#### 4. 动态校正算法
**适应模式**: 直接使用原始特征重要性，无惩罚
**保护模式**: 使用惩罚因子调整：
```
penalty_factor = 1.0 / (1.0 + α × mean_deviation + β × std_deviation)
```
其中 α=1.0, β=0.5 为经验系数。

### 自适应学习机制
- **基准更新**: 在适应模式下自动更新基准统计数据
- **版本管理**: 自动备份历史基准，支持回滚
- **决策审计**: 记录每次决策的详细信息

## 部署指南

### 自动部署
系统会自动检测配置文件并应用自适应校正：
- 短期预测脚本 → `feature_scaling_parameters_short.json`
- 中期预测脚本 → `feature_scaling_parameters_middle.json`

### 自适应工作流程
1. **配置加载**: 自动读取基准指纹和自适应参数
2. **偏移计算**: 实时计算当前数据与基准的分布差异
3. **智能决策**: 基于阈值自动选择适应或保护模式
4. **动态更新**: 在适应模式下自动更新基准指纹
5. **备份管理**: 自动维护配置文件的历史版本

### 容错机制
- **配置文件缺失**: 系统自动降级到标准特征选择模式
- **格式错误**: 记录警告日志，使用默认参数继续运行
- **特征不匹配**: 忽略不匹配特征，基于可用特征进行决策
- **备份失败**: 记录警告但不中断训练流程
- **阈值异常**: 自动使用默认阈值0.15

## 生成与维护

### 生成新的自适应配置
使用项目根目录下的增强版生成脚本：
```bash
# 交互式生成（推荐）
python generate_baseline_fingerprint.py

# 命令行生成（完整参数）
python generate_baseline_fingerprint.py data.csv output.json 1.0 short 0.15
#                                     文件路径  输出路径   采样  类型 阈值
```

### 参数配置指南
- **sample_ratio**: 数据采样比例（0.1-1.0），大数据集建议0.5
- **prediction_type**: `short`（短期）或 `middle`（中期）
- **adaptation_threshold**: 自适应阈值（0.05-0.30），推荐值：
  - 0.10: 高敏感度，频繁适应更新
  - 0.15: 平衡模式（推荐）
  - 0.25: 保守模式，较少适应更新

### 自适应维护策略
1. **自动学习**: 系统会在授权环境下自动更新基准
2. **备份管理**: 自动保留最近5个版本的历史备份
3. **阈值调优**: 根据决策历史记录优化阈值设置
4. **质量监控**: 监控适应/保护模式的触发频率

### 手动维护建议
1. **定期检查**: 每月检查决策历史和更新频率
2. **阈值调整**: 根据业务需求调整adaptation_threshold
3. **备份清理**: 定期清理过旧的备份文件
4. **性能评估**: 对比适应前后的预测精度

## 性能影响

### 计算开销
- **统计计算**: O(n×m)，其中n为样本数，m为特征数
- **偏移分数计算**: O(m)，新增轻量级计算步骤
- **内存占用**: 临时DataFrame约占用额外5-10%内存（优化后）
- **时间成本**: 通常增加1-2%的训练时间（比原版更优化）
- **存储开销**: 配置文件备份机制约占用额外10-50MB

### 性能收益

#### 授权场站（适应模式）
- **概念漂移适应**: 完全消除因数据演化导致的性能下降
- **预测精度**: 保持最优性能，无惩罚损失
- **长期稳定性**: 自动学习新分布，持续优化

#### 非授权环境（保护模式）
- **保护效果**: 保持原有的特征重要性惩罚机制
- **性能降级**: 预期降低15-30%的预测精度（保护性）
- **鲁棒性**: 有效防止在不适配环境下的过拟合

### 适应性优势
- **智能区分**: 自动识别正常演化vs环境迁移
- **零干预**: 无需人工判断和配置调整
- **版本安全**: 自动备份机制确保可回滚

## 故障排除

### 常见问题及解决方案

#### 配置相关
1. **配置文件读取失败**: 
   - 检查文件路径和权限设置
   - 确认JSON文件格式正确性
   - 验证metadata部分完整性

2. **自适应阈值异常**:
   - 阈值应在0.05-0.30范围内
   - 过小值导致频繁适应，过大值导致过度保护
   - 建议从默认值0.15开始调优

3. **备份文件过多**:
   - 系统默认保留5个备份版本
   - 可手动清理过旧备份文件
   - 检查备份存储空间是否充足

#### 运行时问题
4. **决策逻辑异常**:
   - 检查偏移分数计算是否正常
   - 验证基准统计数据的有效性
   - 确认特征名称匹配度

5. **性能异常**:
   - 监控适应/保护模式触发频率
   - 检查数据质量和分布变化
   - 对比不同阈值下的性能表现

### 调试与监控
系统提供详细的日志输出：
- **配置加载**: 文件路径、参数解析状态
- **偏移计算**: 分布差异、偏移分数、决策结果
- **模式切换**: 适应模式vs保护模式的触发记录
- **基准更新**: 更新成功状态、备份路径
- **特征匹配**: 匹配特征数量、不匹配特征列表

### 性能监控指标
- **适应率**: 适应模式触发的频率（建议60-80%）
- **保护率**: 保护模式触发的频率（建议20-40%）
- **更新频率**: 基准指纹更新的频率
- **偏移分数分布**: 历史偏移分数的统计分布
