# 测试与场站验收策略

## 自动化测试

```powershell
.\scripts\test-productization.ps1
```

测试范围包括：

1. `backend/tests` 中的完整后端回归，新增测试无需手工加入脚本清单。
2. 数据契约字段、时区、路径和校验和。
3. 原子接入、重复投递、编号冲突和隔离。
4. 处理中断恢复、临时故障回队和指数退避。
5. 目录代理与 HTTP 接入端到端传递。
6. 上报发件箱幂等创建、成功、重试、死信和进程中断恢复。
7. 能力事实表和前端生产构建。
8. Compose 展开、PowerShell 解析和 Linux 脚本语法。
9. SCADA 样本质量、幂等入库、数据新鲜度、预测消费状态和上报状态。
10. 五类 SCADA 规范观测和业务投影。
11. NWP 业务处理的完成、重复、重试和隔离。
12. 预测输入快照、模型审批拒绝回滚、制品篡改检测。
13. 运行控制中心聚合状态和 CycloneDX SBOM 生成。

## SCADA 独立测试床

```powershell
.\scripts\scada-test.ps1 -Action test
```

该套件使用真实 `scada_worker.py`，验证 25 个 C104 点位、五类指标、质量码、五场站上送、网络延迟、断线重连、限功率一致性和陈旧数据。NWP 仿真器同时验证正常、缺失值、非法时间和陈旧文件。完整开发环境会将样本送入真实后端，验证拒绝、降级、业务投影、批次记录和自动恢复。详细说明见 `SCADA_TEST_ENVIRONMENT.md` 与 `SCADA_CLOSED_LOOP.md`。

## 故障演练

| 故障 | 操作 | 通过标准 |
| --- | --- | --- |
| 下一跳断网 | 阻断代理到接入 API | 数据保留在 inbox，恢复后自动发送一次 |
| 后端重启 | 接收后立即停止服务 | 已完成原子落盘的数据仍可查询 |
| Worker 中断 | 发送过程中终止 Worker | 超时后任务从 processing 回到 retry |
| 目标返回 503 | 模拟服务维护 | 按退避时间重试，载荷摘要不变 |
| 目标返回 400 | 模拟契约拒绝 | 进入 dead，运维可查看原因并人工重投 |
| 重复文件 | 重复摆渡相同文件 | 目标返回重复成功，不生成第二份业务消息 |
| 文件篡改 | 修改载荷但保留清单 | 接入 API 拒绝并报告 SHA256 不一致 |
| 发布包篡改 | 修改任一归档 | `verify-release.sh` 失败，部署停止 |
| 模型制品篡改 | 注册后修改模型文件 | 审批或回滚摘要校验失败 |
| NWP 批次过期 | 停止 NWP 文件生成 | 能力事实表和运行控制中心显示过期 |
| 磁盘接近满载 | 将运行盘使用率提升到阈值 | 运行控制中心产生告警，归档任务可执行 |

## 场站验收

1. 连续运行至少七天，覆盖链路抖动和每日预测周期。
2. SCADA 与服务器统一时钟源，时钟偏差满足现场规范。
3. 核对点表、单位、倍率、质量位、缺失值和重复值。
4. 比较源端文件数、接入消息数、业务入库数和隔离数。
5. 验证预测生成时限、页面刷新延迟和操作员并发访问。
6. 使用真实下游测试端验证幂等键、回执、超时和重试。
7. 演练离线升级、失败回滚、数据库恢复和密钥轮换。
8. 执行 `FAT_CHECKLIST.md` 并保存报告、截图、日志和签字记录。
