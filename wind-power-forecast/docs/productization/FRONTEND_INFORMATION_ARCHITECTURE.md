# 前端信息架构整理记录

## 目标

本轮整理围绕场站人员的三类高频任务展开：查看运行状态，处理预测结果，维护数据与异常。原有业务路由继续保留，导航层先完成合并、重命名和降级展示，降低误删仍在使用功能的风险。

## 审计结论

| 区域 | 发现 | 处理 |
| --- | --- | --- |
| 主导航 | 多个分组可同时展开，侧栏高度超出视口，切换页面后滚动位置继续保留 | 同一时间仅展开一个分组，路由切换时打开当前分组并复位滚动位置 |
| 预测任务 | 页面顶部运行矩阵与下方任务卡重复提供启停操作，趋势列没有有效内容 | 删除重复矩阵，保留场站状态矩阵和带执行信息的任务卡 |
| 账号权限 | 用户列表与角色管理分别占用一个导航入口，职责关系不直观 | 合并为账号与权限页面，通过账号管理和角色权限两个页签切换 |
| 数据质量 | 数据质量入口放在运维分组，和数据补齐、气象接入距离较远 | 移入数据管理分组 |
| 上报功能 | 当前阶段没有真实上报需求，主导航仍突出展示配置入口 | 默认从主导航和运行状态页隐藏，通过 `VITE_REPORTING_ENABLED=true` 显式启用 |
| 告警列表 | 常见桌面宽度下列数过多，告警内容与操作按钮发生重叠 | 合并模块与告警内容，保留通知信息，固定操作列宽度 |
| 功率曲线 | 名称容易与预测曲线对比混淆，页面缺少职责说明 | 更名为风速功率曲线并补充用途说明，当前异常识别口径保持不变 |
| 登录页 | 公告内容为固定演练文案，联系管理员链接没有实际动作 | 改为真实登录提示，将无动作链接改为说明文字 |
| Vite 运行 | 浏览器加载 CommonJS 兼容模块时发生空白页 | 将兼容逻辑改为浏览器和 Node 测试均可加载的 ESM 模块 |

## 当前导航职责

| 分组 | 页面职责 |
| --- | --- |
| 首页总览 | 查看全局功率、准确率、气象和场站链路摘要 |
| 预测运行 | 管理预测任务，进入人工修正 |
| 结果分析 | 查看预测曲线与考核结果，查看月度准确率，诊断风速功率曲线 |
| 数据管理 | 接入气象数据，补齐历史数据，维护数据质量与限电标记 |
| 运行保障 | 查看实时链路与模型状态，处置告警 |
| 系统配置 | 维护场站、数据源、账号权限、基础设置、数据库和审计日志 |

## 保留的兼容能力

1. `/users/roles` 继续可访问，并跳转到账号与权限页面的角色权限页签。
2. `/reportmanagement` 路由继续保留，启用开关后恢复导航入口。
3. 预测、告警、场站和数据库接口没有变更。
4. 预测算法与模型制品没有变更。

## 后续候选项

1. 将运行控制中心按实时输入、预测追溯、模型治理拆分为页签，进一步减少长页面滚动。
2. 为首页每一项指标增加数据来源和新鲜度提示，清除剩余的展示性占位状态。
3. 统一空状态、异常状态和未启用状态的文案与颜色。
4. 在 1366×768 和更小宽度下继续优化表格列优先级与顶部工具栏布局。
