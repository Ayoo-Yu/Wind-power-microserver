# 自动上报调度器说明

## 功能概述

自动上报调度器是一个后台服务，用于定时自动上报风电场的功率数据。该系统支持：

- **精确定时上报**：每15分钟整点提前30秒自动上报
- **多种数据类型**：支持实际功率、超短期预测、长期预测数据上报
- **后台持续运行**：前端关闭后仍可继续执行自动上报
- **灵活配置**：可为不同风电场配置不同的上报策略
- **完整日志记录**：记录每次上报的详细日志和结果

## 上报时间策略

### 固定时间点上报
系统在以下时间点自动执行上报：
- XX:14:30（每小时的14分30秒）
- XX:29:30（每小时的29分30秒）
- XX:44:30（每小时的44分30秒）
- XX:59:30（每小时的59分30秒）

### 时间设计原理
- **提前30秒**：确保在15分钟整点前获取到最新数据
- **避免冲突**：错开系统可能的数据更新时间窗口
- **高精度**：使用秒级精度控制，确保时间准确性

## 系统架构

### 后端组件
1. **调度器核心** (`BackgroundScheduler`)
   - 基于APScheduler实现
   - 每秒检查一次当前时间
   - 精确控制上报时机

2. **上报逻辑** (`execute_report`)
   - 根据配置类型获取相应数据
   - 发送HTTP请求到目标服务器
   - 记录执行日志和结果

3. **配置管理**
   - 数据库存储上报配置
   - 支持启用/禁用状态控制
   - 记录最后上报时间

### 前端控制界面
- **调度器状态显示**：实时显示运行状态
- **控制按钮**：启动/停止/刷新调度器
- **下次上报时间**：显示即将到来的上报时间点
- **配置管理**：创建和编辑上报配置

## 使用指南

### 1. 配置上报任务

1. 访问"数据上报配置与管理"页面
2. 在"风电场站管理"部分添加风电场信息
3. 在"上报配置管理"部分创建上报配置：
   - 选择风电场
   - 选择上报类型（实际功率/超短期预测/长期预测）
   - 输入目标IP和端口
   - 设置上报周期（建议15分钟）
   - 启用配置

### 2. 启动调度器

调度器在后端服务启动时会自动启动，也可以通过前端界面控制：

1. 查看"自动上报调度器"卡片状态
2. 如果显示"已停止"，点击"启动"按钮
3. 确认状态变为"运行中"

### 3. 监控上报状态

1. **实时状态**：调度器卡片显示运行状态和下次上报时间
2. **上报日志**：在"上报日志"表格中查看历史记录
3. **后端日志**：服务器日志文件记录详细执行信息

## API接口

### 调度器控制接口

#### 获取调度器状态
```http
GET /api/report/scheduler/status
```

响应示例：
```json
{
  "running": true,
  "next_report_times": ["10:29:30", "10:44:30"]
}
```

#### 启动调度器
```http
POST /api/report/scheduler/start
```

#### 停止调度器
```http
POST /api/report/scheduler/stop
```

### 配置管理接口

#### 获取上报配置
```http
GET /api/report/configs
```

#### 创建上报配置
```http
POST /api/report/configs
```

请求体示例：
```json
{
  "farm_id": 1,
  "report_type": "actual",
  "target_ip": "192.168.1.100",
  "target_port": 8080,
  "report_interval": 15,
  "is_enabled": true
}
```

## 数据格式

### 上报数据结构
```json
{
  "report_type": "actual",
  "timestamp": "2025-01-07T10:14:30",
  "data": [
    {
      "turbine_id": "T001",
      "power": 1250.5,
      "wind_speed": 8.2,
      "timestamp": "2025-01-07T10:14:00"
    }
  ]
}
```

### 支持的数据类型
- **actual**: 实际功率数据
- **forecast_short**: 超短期预测数据
- **forecast_long**: 长期预测数据

## 故障排除

### 常见问题

1. **调度器显示已停止**
   - 检查后端服务是否正常运行
   - 点击"启动"按钮重新启动调度器
   - 查看后端日志是否有错误信息

2. **上报失败**
   - 检查目标服务器IP和端口是否正确
   - 确认网络连接是否正常
   - 查看上报日志中的错误信息

3. **没有执行自动上报**
   - 确认配置已启用
   - 检查调度器是否运行
   - 确认当前时间是否在上报时间点

### 日志查看

后端日志位置：`logs/app.log`

关键日志信息：
- 调度器启动：`上报调度器启动成功`
- 定时检查：`定时检查上报任务`
- 上报触发：`触发定时上报`
- 上报完成：`定时上报完成`

## 技术特性

### 高可靠性
- **并发控制**：使用锁机制防止重复执行
- **异常处理**：完善的错误捕获和日志记录
- **自动恢复**：调度器异常时可重新启动

### 高精度
- **秒级控制**：精确到秒的时间控制
- **重复检测**：避免因时间偏差导致的重复上报
- **时间校准**：基于系统时间进行精确判断

### 可扩展性
- **模块化设计**：上报逻辑与调度逻辑分离
- **配置灵活**：支持多种上报类型和目标
- **易于维护**：清晰的代码结构和完整文档

## 注意事项

1. **服务器时间**：确保服务器时间准确，影响上报时机
2. **网络稳定**：保证与目标服务器的网络连接稳定
3. **数据完整性**：确保数据库中有足够的数据供上报使用
4. **监控告警**：建议配置监控系统，及时发现上报异常
5. **备份恢复**：定期备份上报配置和日志数据
