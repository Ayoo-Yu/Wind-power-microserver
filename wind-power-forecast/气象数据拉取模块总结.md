# 气象数据拉取模块实现总结

## 项目概述

本项目为华中科技大学风电功率预测平台成功实现了"气象预报数据拉取模块"，该模块能够通过SSH远程连接自动获取气象数据，经过数据处理后存储到数据库中，为风电功率预测提供基础数据支持。

## 技术架构

### 前端技术栈
- **Vue 3**: 现代化前端框架
- **Element Plus**: UI组件库，保持与现有系统风格一致
- **Vue Router**: 前端路由管理
- **Axios**: HTTP客户端，用于API调用

### 后端技术栈
- **Flask**: Python轻量级Web框架
- **SQLAlchemy**: ORM数据库操作
- **Paramiko**: SSH客户端库，实现远程连接
- **Pandas**: 数据处理和分析
- **APScheduler**: 定时任务调度器
- **PostgreSQL**: 主数据库

### 核心模块设计

```
wind-power-forecast/
```

## API接口设计

### REST API 端点

| 方法 | 端点 | 功能 |
|------|------|------|
| GET | `/api/weather/connections` | 获取SSH连接列表 |
| POST | `/api/weather/connections` | 创建SSH连接 |
| PUT | `/api/weather/connections/<id>` | 更新SSH连接 |
| DELETE | `/api/weather/connections/<id>` | 删除SSH连接 |
| POST | `/api/weather/connections/<id>/test` | 测试SSH连接 |
| GET | `/api/weather/tasks` | 获取拉取任务列表 |
| POST | `/api/weather/tasks` | 创建拉取任务 |
| DELETE | `/api/weather/tasks/<id>` | 删除拉取任务 |
| POST | `/api/weather/tasks/<id>/run` | 立即执行任务 |
| POST | `/api/weather/tasks/<id>/toggle` | 启用/停用任务 |
| GET | `/api/weather/tasks/<id>/logs` | 获取任务日志 |
| GET | `/api/weather/scheduler/status` | 获取调度器状态 |
