# 气象数据拉取模块使用说明

## 模块概述

气象数据拉取模块是风电功率预测平台的重要组成部分，用于自动化地从远程气象服务器获取数据，并将其处理后存储到本地数据库中。

## 功能特性

### 1. SSH连接管理
- 支持密码和密钥两种认证方式
- 连接测试功能
- 连接状态监控

### 2. 数据拉取任务
- 基于Cron表达式的定时任务
- 文件模式匹配
- 多种数据处理选项
- 任务状态监控

### 3. 数据处理
- 自动列名映射
- 数据插值和清洗
- 数据范围检查
- 灵活的缺失值处理策略

### 4. 日志记录
- 详细的执行日志
- 错误追踪
- 处理结果统计

## 使用流程

### 步骤1：创建SSH连接

```bash
# API请求示例
POST /api/weather/connections
{
    "name": "气象站01",
    "host": "192.168.1.100",
    "port": 22,
    "username": "weather",
    "auth_type": "password",
    "password": "your_password"
}
```

### 步骤2：测试连接

```bash
POST /api/weather/connections/1/test
```

### 步骤3：创建数据拉取任务

```bash
POST /api/weather/tasks
{
    "name": "每日气象数据拉取",
    "connection_id": 1,
    "remote_path": "/data/weather",
    "file_pattern": "weather_*.csv",
    "schedule": "0 6 * * *",
    "target_table": "train_pre_middle",
    "processing_options": {
        "read_options": {
            "separator": ",",
            "encoding": "utf-8"
        },
        "interpolate": true,
        "missing_value_strategy": "drop",
        "range_check": true
    }
}
```

### 步骤4：手动执行任务（可选）

```bash
POST /api/weather/tasks/1/run
```

## 数据处理配置选项

### 读取选项 (read_options)
- `separator`: 分隔符，默认为逗号
- `header_row`: 表头行，默认为0
- `encoding`: 编码格式，默认为utf-8
- `skip_rows`: 跳过的行数，默认为0

### 数据处理选项
- `interpolate`: 是否进行插值，默认false
- `missing_value_strategy`: 缺失值策略
  - `drop`: 删除缺失值行
  - `fill_zero`: 用0填充
  - `fill_mean`: 用平均值填充
- `range_check`: 是否进行数据范围检查
- `column_mapping`: 列名映射字典

### 时间筛选选项 (time_filter)
- `start_time`: 开始时间
- `end_time`: 结束时间
- `resample_frequency`: 重采样频率（如'1H', '15T'等）

## Cron表达式示例

```
# 每天凌晨6点执行
0 6 * * *

# 每小时执行
0 * * * *

# 每15分钟执行
*/15 * * * *

# 每周一上午9点执行
0 9 * * 1

# 每月1号凌晨2点执行
0 2 1 * *
```

## 支持的目标数据表

- `train_pre_middle`: 中期预测特征表
- `train_pre_short`: 短期预测特征表
- `train_pre_supershort`: 超短期预测特征表

## 支持的文件格式

- CSV文件 (.csv)
- 文本文件 (.txt)
- 数据文件 (.data)

## 数据列要求

必须包含以下列（支持自动匹配列名）：
- `time`: 时间戳
- `temperature`: 温度
- `humidity`: 湿度
- `wind_speed`: 风速
- `wind_direction`: 风向

## API端点列表

### SSH连接管理
- `GET /api/weather/connections` - 获取连接列表
- `POST /api/weather/connections` - 创建连接
- `PUT /api/weather/connections/<id>` - 更新连接
- `DELETE /api/weather/connections/<id>` - 删除连接
- `POST /api/weather/connections/<id>/test` - 测试连接

### 任务管理
- `GET /api/weather/tasks` - 获取任务列表
- `POST /api/weather/tasks` - 创建任务
- `DELETE /api/weather/tasks/<id>` - 删除任务
- `POST /api/weather/tasks/<id>/run` - 立即执行任务
- `POST /api/weather/tasks/<id>/toggle` - 启用/停用任务

### 日志查看
- `GET /api/weather/tasks/<id>/logs` - 获取任务执行日志

### 调度器管理
- `GET /api/weather/scheduler/status` - 获取调度器状态
- `POST /api/weather/tasks/<id>/schedule` - 添加到调度器
- `POST /api/weather/tasks/<id>/unschedule` - 从调度器移除

## 错误处理

模块提供了完善的错误处理机制：

1. **连接错误**: SSH连接失败时会记录详细错误信息
2. **文件错误**: 文件不存在或格式错误时会跳过并记录
3. **数据错误**: 数据验证失败时会提供具体错误原因
4. **处理错误**: 数据处理异常时会回滚并记录错误

## 注意事项

1. 确保SSH连接的网络可达性
2. 验证远程服务器的文件路径和权限
3. 定期检查任务执行日志
4. 合理设置定时任务间隔，避免频繁执行
5. 监控数据库存储空间
6. 定期备份重要配置和数据

## 故障排除

### 常见问题

1. **SSH连接失败**
   - 检查网络连接
   - 验证用户名和密码
   - 确认SSH服务状态

2. **文件下载失败**
   - 检查文件路径是否正确
   - 验证文件权限
   - 确认磁盘空间

3. **数据处理失败**
   - 检查文件格式
   - 验证列名映射
   - 查看详细错误日志

4. **定时任务不执行**
   - 确认任务已启用
   - 检查Cron表达式格式
   - 查看调度器状态

### 日志级别说明

- `info`: 正常信息，如任务开始、完成
- `success`: 成功操作，如文件处理成功
- `warning`: 警告信息，如未找到文件
- `error`: 错误信息，如连接失败、处理异常
